# Portfolio — Angelo Clauin ⚡

Portfolio web moderne, ultra-rapide et responsive conçu pour **Angelo Clauin** (Fullstack Developer).

Construit avec **React 18**, **TypeScript**, **Vite** et **Tailwind CSS**, intégrant l'ensemble des éléments de son parcours professionnel (Metis Digital, intégrations NDC aériennes), ses projets phares (Gazes, AI Web Annotator, Homelab auto-hébergé) et ses compétences.

---

## 🌟 Points Forts du Portfolio

1. **Terminal Système & Observabilité Interactive** :
   - `$ metis-cli ndc-integration` : Démonstration interactive du flux transactionnel NDC (Shopping, Pricing, OrderCreate, Ancillaries) pour Vueling, Volotea, Air France/KLM et Kyte.
   - `$ gazes-engine` : Simulation live du moteur de streaming torrent séquentiel en Go avec distribution maillée WebRTC in-browser.
   - `$ homelab-cluster` : Statut du cluster bare-metal auto-hébergé (NixOS, Gitea, mail server, Grafana, OpenTelemetry, Vault).
   - `$ whoami` : Fiche synthétique d'ingénierie et parcours.

2. **Détail Expérience Métier Metis Digital** :
   - Sélecteur interactif de transporteurs aériens NDC (Vueling VY avec 19 fonctionnalités ancillaires vérifiées, Volotea V7 avec gestion des frais de carte et bugfix bac à sable, AFKL, agrégateur GDS Kyte).
   - Couche d'infrastructure partagée (`safeClone`, conversion multi-devises, reshop).
   - Framework de test E2E Playwright data-driven validé avec Zod.

3. **Showcase Projets Phares avec Schémas d'Architecture** :
   - **Gazes 🎬⚡** : Plateforme de streaming torrent P2P WebRTC ("YouTube for Torrents") avec blueprint de flux.
   - **AI Web Annotator 🎯** : Extension Chrome MV3 de capture et de génération de contexte DOM pour LLMs.
   - **Homelab & Cluster Souverain 🖥️** : Infrastructure IaC NixOS, Docker, observabilité continue.

4. **Matrice de Compétences Filtrable** :
   - Frontend (Vue 3, Nuxt 4, TypeScript, Vuetify 4, Pinia, Zod).
   - Backend & APIs (Node.js, Express, Go, PostgreSQL, Sequelize, Redis, MongoDB).
   - DevOps & Cloud (Nix/NixOS, Docker, Podman, Kubernetes, GitLab CI, Grafana, Vault).
   - Testing & Qualité (Playwright, Mocha, Chai, Zod).
   - Protocoles (IATA NDC, WebRTC, BitTorrent, SOAP/XML, REST).

5. **Actions & Téléchargement Direct** :
   - Bouton de téléchargement du CV au format PDF original (`resume.pdf`).
   - Bouton de copie en un clic de l'adresse email professionnelle avec retour visuel immédiat.

## 🚀 Démarrage Rapide

```bash
# Installation des dépendances (déjà effectuée)
npm install

# Lancer le serveur de développement local (Vite)
npm run dev

# Compiler pour la production
npm run build

# Prévisualiser le build de production
npm run preview
```
